# GitHub Pages setup

1. Open the repository on GitHub and go to **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and the `/docs` folder, then save.
4. Wait for the Pages deployment to finish and verify both language pages and their links.

Expected paths after GitHub Pages is enabled:

- English: `https://chiffon95.github.io/ledgram/privacy/`
- Korean: `https://chiffon95.github.io/ledgram/privacy/ko.html`

These URLs are expected locations only; do not treat them as live until GitHub reports a successful deployment and both return successfully.

Before using the policy contact field, replace the clearly marked placeholder in both HTML files with the same verified public support email address.
