기기에 저장되는 정보

LEDgram은 Editor 설정을 기기의 앱 로컬 저장소에 저장합니다. 저장 항목에는 문구, 글자색과 배경색, 굵게·기울임·밑줄 스타일, 표현 방식, 움직임과 효과 선택, 이동 속도와 효과 속도가 포함됩니다.

또한 광고 표시 빈도를 제어하기 위해 Display 종료 횟수와 전면 광고 표시 시각을 기기에 저장합니다. LEDgram은 로컬에 저장된 Editor 콘텐츠나 빈도 제어 데이터를 Gowl Labs로 전송하지 않습니다.

사용자 콘텐츠와 앱 서비스

LEDgram은 사용자의 LED 문구를 Gowl Labs에 업로드하지 않습니다. 앱에는 사용자 계정 기능이 없으며 Gowl Labs가 운영하는 사용자 콘텐츠용 백엔드나 서버도 없습니다.

LEDgram은 Firebase Analytics 또는 Firebase Crashlytics를 사용하지 않습니다.

광고 및 동의

LEDgram은 Editor에 광고를 표시하기 위해 Google Mobile Ads를 사용하고, 해당하는 경우 동의 요청 및 개인정보 선택 제공을 위해 Google User Messaging Platform(UMP)을 사용합니다. Display 모드 자체에는 광고가 표시되지 않습니다.

Google의 Mobile Ads SDK 공개 자료에 따르면, 해당 SDK는 광고, 분석 및 부정행위 방지 목적으로 특정 정보를 자동으로 수집하고 공유합니다. 여기에는 IP 주소, 앱과의 사용자 상호작용, 진단 정보, 기기 또는 계정 식별자가 포함될 수 있습니다. Google은 자체 약관과 정책에 따라 이 정보를 처리합니다.

  • Google 개인정보처리방침
  • Google 서비스를 사용하는 사이트 또는 앱의 정보 사용 방식
  • Google Mobile Ads SDK 데이터 공개 안내
  • Google UMP 개인정보 보호 문서

사용자 선택 및 초기화

LEDgram의 설정 화면에서 Editor 설정을 기기 내에서 초기화할 수 있습니다. Editor 초기화는 목적과 관리 방식이 서로 다른 Google UMP 동의 또는 개인정보 선택, 광고 상태, 광고 빈도 제어용 횟수와 시각을 초기화하지 않습니다.

필요한 경우 LEDgram은 Google UMP가 관리하는 선택을 위한 개인정보 선택 메뉴를 설정에 제공합니다. Android 시스템 설정에서도 기기의 광고 식별자 관련 제어 기능을 제공할 수 있습니다.

처리방침 변경

향후 LEDgram의 동작이 변경되면 이 처리방침도 업데이트될 수 있습니다. 위 시행일은 현재 처리방침의 버전을 나타냅니다.
