# LEDgram

LEDgram은 휴대폰 화면을 콘서트, 응원, 행사 및 간단한 시각 메시지 전달용 맞춤형 전체화면 LED 전광판으로 사용할 수 있게 하는 Android 앱입니다.

- **앱 이름:** LEDgram
- **패키지:** `com.gwolbisa.ledgram`
- **스튜디오:** GWOL LABS

## 프로젝트 상태

LEDgram은 초기 개발 단계입니다. 마일스톤 1에서 처음으로 동작하는 수직 기능 흐름을 제공합니다.

구현됨:

- 단일 모듈 Android 프로젝트 골격
- 세로형 Editor → 가로형 전체화면 Display 흐름
- 고정된 Editor 앱 바와 실시간 미리보기, 독립적으로 스크롤되는 설정 영역, 내비게이션 바와 키보드를 피하는 Start Display 버튼
- 모든 움직임 + 시각 효과 조합을 재생하는 실시간 미리보기(빈 입력, 공백뿐인 입력 또는 줄바꿈뿐인 입력에는 정규화된 실제 메시지와 전체 화면 보기 상태를 바꾸지 않는 미리보기 전용 `Hello!` 샘플 표시)
- 움직임(고정, 오른쪽→왼쪽, 왼쪽→오른쪽)과 시각 효과(없음, 깜박임, 숨쉬기, 부드러운 점멸)를 독립적인 레이어로 합성하고, 흐르기 숨쉬기의 크기 변환 기준점을 진행 방향의 앞쪽 가장자리에 맞춰 시각 효과가 이동 경로에 영향을 주지 않는 Text + Glow 렌더링
- 0.25x~5.0x 범위에서 선택하는 독립적인 움직임 속도와 효과 속도 조절. 움직임 속도는 흐르기의 수평 이동에만, 효과 속도는 미리보기와 전체 화면의 깜박임·숨쉬기·부드러운 점멸 타이밍에만 적용
- 정적 표시는 사용자가 넣은 모든 줄바꿈을 보존하고 필요하면 자동 줄바꿈하며, 줄 수 제한 없이 가운데 정렬된 전체 여러 줄 문구가 보일 때까지 자동 축소. 흐르기는 렌더링할 때만 저장된 줄바꿈을 평탄화해 항상 한 줄로 스크롤하며, 다시 정적으로 전환하면 전체 여러 줄 구조가 복원됨
- 굵게, 기울임, 밑줄 글자 스타일
- HSV 슬라이더, HEX 입력, 색상 교환, 대비 경고 및 세션 한정 최근 색상을 지원하는 기본/사용자 지정 글자색·배경색
- 저장된 여러 줄 메시지, 글자색/배경색, 글자 스타일, 렌더링 스타일, 움직임, 시각 효과, 움직임 속도 및 효과 속도를 앱 재시작 후에도 복원하는 Preferences DataStore 저장 기능. 미리보기 전용 `Hello!` 샘플과 최근 색상은 저장하지 않음
- 몰입형 Display 모드, 창 최대 밝기 및 화면 켜짐 유지
- 탭하면 나타나는 Exit 오버레이
- 설정 버튼과 시스템 언어 정보, 동적 앱 버전, 스튜디오 정보 및 개인정보 처리방침/오픈 소스 라이선스 자리표시자를 제공하는 최소 설정 화면

계획됨:

- Dot-Matrix 렌더링
- AdMob 및 UMP 동의 지원
- Firebase Analytics 및 Crashlytics
- 앱 내 언어 전환 및 최종 프로덕션 법적 고지

## 마일스톤 1 범위

현재 MVP는 명시적인 줄바꿈을 개수 제한 없이 포함할 수 있는 100 유니코드 코드 포인트 메시지 편집과 글자 스타일·색상 선택을 지원하며, Editor 미리보기와 가로형 전체화면 Text + Glow 표시 모두에서 고정 또는 양방향 흐르기 움직임과 없음·깜박임·숨쉬기·부드러운 점멸 시각 효과를 독립적으로 조합할 수 있습니다. 움직임과 시각 효과 변환은 독립적으로 합성됩니다. 흐르기 중 숨쉬기 크기 변화는 진행 방향의 앞쪽 가장자리를 기준으로 하므로 수평 이동 경로를 바꾸지 않습니다. 움직임 속도와 효과 속도는 서로 독립적인 0.25x~5.0x 조절 항목입니다. 움직임 속도는 흐르기의 수평 이동에만 영향을 주고, 효과 속도는 깜박임·숨쉬기·부드러운 점멸 타이밍에만 영향을 줍니다. 정적 표시는 모든 명시적 줄바꿈을 보존하고 필요하면 자동 줄바꿈하며, 고정된 줄 수 제한이나 줄임표 없이 가로·세로 가운데 정렬된 전체 여러 줄 문구가 보일 때까지 자동 축소합니다. 흐르기는 글자 크기를 주로 사용 가능한 높이에 맞추고 렌더링 내용을 만들 때만 저장된 줄바꿈과 인접 공백을 합쳐 항상 한 줄로 스크롤합니다. 다시 정적으로 전환하면 저장된 정확한 여러 줄 구조가 복원됩니다. 미리보기도 같은 움직임별 규칙을 따릅니다. Preferences DataStore는 메시지, 색상, 글자 스타일, 렌더링 스타일, 움직임/효과 선택 및 두 속도를 앱 재시작 후에도 복원합니다. 빈 입력 또는 공백뿐인 입력에는 Editor 메시지를 바꾸거나 저장하지 않고 `DisplayConfig`에도 들어가지 않으며 전체 화면 보기를 활성화하지 않는 미리보기 전용 `Hello!` 샘플이 표시됩니다. 최근 색상은 계속 현재 세션에서만 유지됩니다. 설정 화면은 시스템 기본 언어를 안내하지만 앱 내 언어 전환은 지원하지 않으며, 개인정보 처리방침과 오픈 소스 라이선스 항목은 자리표시자입니다. Dot Matrix는 아직 구현되지 않았습니다. 광고, 분석 및 네트워크 접근은 포함하지 않습니다.

## 기술 스택

- Android Gradle Plugin 9.4.1
- Gradle 9.8.0
- Kotlin 2.4.21
- Jetpack Compose 및 Material 3
- 세 개의 Android Activity (`EditorActivity`, `DisplayActivity`, `SettingsActivity`)
- 버전 카탈로그를 사용하는 Gradle Kotlin DSL
- AndroidX Core SplashScreen
- AndroidX Preferences DataStore 1.2.1
- AndroidX Lifecycle 2.10.0
- minSdk 24, compileSdk 36, targetSdk 36
- JDK/JVM 17

## 프로젝트 구조

```text
app/src/main/java/com/gwolbisa/ledgram/
├── data/           # Preferences DataStore 매핑 및 저장소
├── model/          # Parcelable 표시 설정 및 enum
├── ui/
│   ├── components/ # 공유 LED 미리보기/텍스트 렌더링
│   ├── display/    # 가로형 전체화면 표시
│   ├── editor/     # 세로형 메시지 편집기
│   ├── settings/   # 최소 앱 정보 및 법적 고지 자리표시자
│   └── theme/      # Material 테마 및 브랜드 색상
└── util/           # 메시지, 색상, 대비 및 최근 색상 유틸리티
```

## 요구 사항

## 로컬 빌드

저장소 루트에서 다음 명령을 실행합니다.

```bash
./gradlew assembleDebug
./gradlew testDebugUnitTest
./gradlew lintDebug
```

디버그 APK는 `app/build/outputs/apk/debug/` 아래에 생성되며 Git에서 제외됩니다.

## 개발 워크플로

1. `main`에서 목적이 명확한 브랜치를 만듭니다.
2. 마일스톤 변경을 작게 유지하고 추측성 인프라를 추가하지 않습니다.
3. 리뷰 요청 전에 빌드, 단위 테스트 및 lint를 실행합니다.
4. diff를 검토하고 기기 또는 에뮬레이터에서 Editor → Display 흐름을 확인합니다.
5. 로컬 SDK 경로, 서명 파일, 자격 증명 또는 생성된 바이너리를 커밋하지 않습니다.

## 개인정보 보호 및 분석

마일스톤 1은 네트워크 권한을 요청하지 않으며 광고, 동의 SDK, 분석, 비정상 종료 보고 또는 클라우드 업로드를 포함하지 않습니다. Preferences DataStore에는 로컬 Editor UI 설정과 사용자가 입력한 메시지만 저장하며 메시지 내용은 로그로 남기지 않습니다. 계획된 네트워크 통합 기능은 도입 전에 명시적인 개인정보 보호 검토를 거쳐야 합니다.
