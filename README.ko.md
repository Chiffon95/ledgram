# LEDgram

LEDgram은 휴대폰 화면을 콘서트, 응원, 행사 및 간단한 시각 메시지 전달용 맞춤형 전체화면 LED 전광판으로 사용할 수 있게 하는 Android 앱입니다.

- **앱 이름:** LEDgram
- **패키지:** `com.gwolbisa.ledgram`
- **스튜디오:** GWOL LABS

## 프로젝트 상태

LEDgram은 초기 개발 단계입니다. 마일스톤 1에서 처음으로 동작하는 수직 기능 흐름을 제공합니다.

구현됨:

- 단일 모듈 Android 프로젝트 골격
- 세로형 Editor → 가로형 전체화면 Display 흐름
- 고정된 Editor 앱 바와 실시간 미리보기, 독립적으로 스크롤되는 설정 영역, 내비게이션 바와 키보드를 피하는 Start Display 버튼
- 모든 움직임 + 시각 효과 조합을 재생하는 실시간 미리보기(빈 입력 또는 공백뿐인 입력에는 정규화된 실제 메시지와 전체 화면 보기 상태를 바꾸지 않는 미리보기 전용 `Hello!` 샘플 표시)
- 움직임(고정, 오른쪽→왼쪽, 왼쪽→오른쪽)과 시각 효과(없음, 깜박임, 숨쉬기, 부드러운 점멸)를 독립적인 레이어로 합성해 시각적 크기 변화가 흐르기 경로에 영향을 주지 않으면서 모든 조합을 사용할 수 있는 Text + Glow 렌더링
- 0.25x~5.0x 범위에서 선택하는 독립적인 움직임 속도와 효과 속도 조절. 움직임 속도는 흐르기의 수평 이동에만, 효과 속도는 미리보기와 전체 화면의 깜박임·숨쉬기·부드러운 점멸 타이밍에만 적용
- 정적 표시는 가독성을 위해 가운데 정렬된 한 줄 또는 최대 두 줄에 전체 문구를 줄임표·생략·잘림 없이 자동 맞춤. 미리보기도 같은 규칙을 따르고, 흐르기는 높이 중심 글자 크기와 한 줄을 유지하며 가로로 스크롤
- 굵게, 기울임, 밑줄 글자 스타일
- HSV 슬라이더, HEX 입력, 색상 교환, 대비 경고 및 세션 한정 최근 색상을 지원하는 기본/사용자 지정 글자색·배경색
- 몰입형 Display 모드, 창 최대 밝기 및 화면 켜짐 유지
- 탭하면 나타나는 Exit 오버레이
- 설정 버튼과 시스템 언어 정보, 동적 앱 버전, 스튜디오 정보 및 개인정보 처리방침/오픈 소스 라이선스 자리표시자를 제공하는 최소 설정 화면

계획됨:

- Dot-Matrix 렌더링
- 색상 및 Editor 설정 영구 저장
- AdMob 및 UMP 동의 지원
- Firebase Analytics 및 Crashlytics
- 앱 내 언어 전환 및 최종 프로덕션 법적 고지

## 마일스톤 1 범위

현재 MVP는 논리적으로 한 줄인 메시지 편집과 글자 스타일·색상 선택을 지원하며, Editor 미리보기와 가로형 전체화면 Text + Glow 표시 모두에서 고정 또는 양방향 흐르기 움직임과 없음·깜박임·숨쉬기·부드러운 점멸 시각 효과를 독립적으로 조합할 수 있습니다. 움직임과 시각 효과 변환은 독립적으로 합성되므로 깜박임·숨쉬기·부드러운 점멸이 흐르기 경로를 바꾸지 않습니다. 움직임 속도와 효과 속도는 서로 독립적인 0.25x~5.0x 조절 항목입니다. 움직임 속도는 흐르기의 수평 이동에만 영향을 주고, 효과 속도는 깜박임·숨쉬기·부드러운 점멸 타이밍에만 영향을 줍니다. 정적 표시는 전체 문구를 줄임표 없이 가로·세로 가운데 정렬된 한 줄 또는 최대 두 줄에 자동 맞춤합니다. 흐르기는 글자 크기를 주로 사용 가능한 높이에 맞추고 가로 넘침을 한 줄 스크롤로 보여 줍니다. 미리보기도 같은 정적 자동 맞춤 규칙을 따릅니다. 빈 입력 또는 공백뿐인 입력에는 Editor 상태를 바꾸거나 `DisplayConfig`에 들어가거나 전체 화면 보기를 활성화하지 않는 미리보기 전용 `Hello!` 샘플이 표시됩니다. 설정 화면은 시스템 기본 언어를 안내하지만 앱 내 언어 전환은 지원하지 않으며, 개인정보 처리방침과 오픈 소스 라이선스 항목은 자리표시자입니다. Dot Matrix는 아직 구현되지 않았습니다. 최근 색상과 속도 선택은 현재 Editor 세션에서만 유지되며 앱 재시작 후 설정 저장, 광고, 분석 및 네트워크 접근은 포함하지 않습니다.

## 기술 스택

- Android Gradle Plugin 9.4.1
- Gradle 9.8.0
- Kotlin 2.4.21
- Jetpack Compose 및 Material 3
- 세 개의 Android Activity (`EditorActivity`, `DisplayActivity`, `SettingsActivity`)
- 버전 카탈로그를 사용하는 Gradle Kotlin DSL
- AndroidX Core SplashScreen
- minSdk 24, compileSdk 36, targetSdk 36
- JDK/JVM 17

## 프로젝트 구조

```text
app/src/main/java/com/gwolbisa/ledgram/
├── model/          # Parcelable 표시 설정 및 enum
├── ui/
│   ├── components/ # 공유 LED 미리보기/텍스트 렌더링
│   ├── display/    # 가로형 전체화면 표시
│   ├── editor/     # 세로형 메시지 편집기
│   ├── settings/   # 최소 앱 정보 및 법적 고지 자리표시자
│   └── theme/      # Material 테마 및 브랜드 색상
└── util/           # 메시지, 색상, 대비 및 최근 색상 유틸리티
```

## 요구 사항

- Android SDK Platform 36이 설치된 Android Studio
- JDK 17
- Android 7.0(API 24) 이상을 실행하는 Android 기기 또는 에뮬레이터

## 로컬 빌드

저장소 루트에서 다음 명령을 실행합니다.

```bash
./gradlew assembleDebug
./gradlew testDebugUnitTest
./gradlew lintDebug
```

디버그 APK는 `app/build/outputs/apk/debug/` 아래에 생성되며 Git에서 제외됩니다.

## 개발 워크플로

1. `main`에서 목적이 명확한 브랜치를 만듭니다.
2. 마일스톤 변경을 작게 유지하고 추측성 인프라를 추가하지 않습니다.
3. 리뷰 요청 전에 빌드, 단위 테스트 및 lint를 실행합니다.
4. diff를 검토하고 기기 또는 에뮬레이터에서 Editor → Display 흐름을 확인합니다.
5. 로컬 SDK 경로, 서명 파일, 자격 증명 또는 생성된 바이너리를 커밋하지 않습니다.

마일스톤 1은 네트워크 권한을 요청하지 않으며 광고, 동의 SDK, 분석, 비정상 종료 보고 또는 사용자 데이터 저장을 포함하지 않습니다. 계획된 통합 기능은 도입 전에 명시적인 개인정보 보호 검토를 거쳐야 합니다.
